## Clinical Development

### Trial Design & Simulation

- [adaptr](https://github.com/INCEPTdk/adaptr) - R package for adaptive clinical trial simulations.
- [rpact](https://github.com/rpact-com/rpact) - R package for adaptive clinical trial design and analysis.

### Clinical Biostatistics & Analysis

- [lifelines](https://github.com/CamDavidsonPilon/lifelines) - Survival analysis in Python.
- [mmrm](https://github.com/openpharma/mmrm) - R package for fitting mixed models for repeated measures.
- [pycox](https://github.com/havakv/pycox) - Python package for survival analysis and model evaluation using neural networks.
- [riskRegression](https://github.com/tagteam/riskRegression) - R package for time-to-event risk prediction and performance evaluation, including competing risks.
- [survival](https://github.com/therneau/survival) - R package for survival analysis and time-to-event data.

### Clinical Data Exploration

- [teal](https://github.com/pharmaverse/teal) - Shiny framework for building interactive clinical trial data exploration apps.

### Pharmacokinetics (PK) & Pharmacodynamics (PD)

- [brms](https://github.com/paul-buerkner/brms) - R package for fitting Bayesian multilevel models with Stan.
- [nlmixr2](https://nlmixr2.org/) - R package for nonlinear mixed-effects modeling in pharmacokinetic and pharmacodynamic studies.
- [PKNCA](https://github.com/humanpred/pknca) - R package for noncompartmental analysis of pharmacokinetic data.

## Regulatory & Submission Tools

### CDISC Data Standards

- [admiral](https://github.com/pharmaverse/admiral) - R package for creating ADaM datasets from SDTM datasets.
- [cards](https://github.com/pharmaverse/cards) - R package for constructing CDISC Analysis Results Data.
- [pharmaverseadam](https://github.com/pharmaverse/pharmaverseadam) - R package with data examples for analysis data model (ADaM).
- [pharmaversesdtm](https://github.com/pharmaverse/pharmaversesdtm) - R package with data examples for Standard Data Tabulation Model (SDTM).
- [sdtm.oak](https://github.com/pharmaverse/sdtm.oak) - R package to transform raw ODM data to SDTM datasets.
- [sdtmchecks](https://github.com/pharmaverse/sdtmchecks) - R package for validating SDTM datasets.

### Tables, Listings & Figures (TLF)

- [cardinal](https://github.com/pharmaverse/cardinal) - R package with harmonized TLF templates for clinical trial reporting.
- [tern](https://github.com/insightsengineering/tern) - R package for generating TLFs from ADaM datasets.

### Reproducibility and Software Validation

- [logrx](https://github.com/pharmaverse/logrx) - R package for logging and reviewing clinical trial programming runs.
- [riskassessment](https://github.com/pharmaR/riskassessment) - Shiny application for assessing the risk of using R packages.
- [thevalidatoR](https://github.com/insightsengineering/thevalidatoR) - GitHub Action for generating R package validation documentation.
